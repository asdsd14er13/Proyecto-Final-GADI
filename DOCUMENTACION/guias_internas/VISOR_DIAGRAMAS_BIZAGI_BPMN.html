📌 ¿Cómo dibujarlo en Bizagi Modeler en 5 minutos?

  1. Crea 1 Pool: Proceso TO-BE: Sistema Inteligente de Evaluación Adaptativa y Personalización.
  2. Inserta 4 Lanes: Estudiante, Docente de Asignatura, Plataforma BI + IA, Comité de Tutoría y Bienestar.
  3. En la Lane de Plataforma BI + IA, asigna a las tareas el tipo Service Task (⚙️) (clic derecho ➔ Task Type ➔ Service).
  4. En la Lane de Tutoría, usa una Business Rule Task (📋) para la prescripción de intervenciones personalizadas.
  5. Agrega 4 Anotaciones de Texto en Verde vinculadas a las tareas con las Mejoras 1, 2, 3 y 4.
User Task (👤): Tarea ejecutada por una persona en un software.
Manual Task (✍️): Tarea física o sin sistema (Excel local, papel).
Service Task (⚙️): Tarea 100% automatizada (SSIS, Python, SSAS).
Business Rule Task (📋): Regla de negocio automatizada o matriz de decisión.
Exclusive Gateway (X): Decisión condicional sí/no.
